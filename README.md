# Qué hace

Gestiona solicitudes académicas desde un menú de consola.
Guarda los cambios para conservarlos entre ejecuciones.

# Tecnología

Python 3 y JSON, sin librerías externas.

# Cómo ejecutar

Desde la carpeta del proyecto: `python app.py`.

# Funciones

- Registrar solicitud.
- Cambiar estado.
- Asignar responsable.
- Listar o filtrar solicitudes.
- Ver reporte.

# Alcance

Versión inicial, pendiente de diagnóstico y refactoring para el TPI.
