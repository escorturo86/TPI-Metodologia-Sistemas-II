# Sistema de Gestión de Solicitudes Académicas

## Descripción

Programa sencillo en Python que permite gestionar solicitudes académicas desde un menú de consola. Los datos se guardan en un archivo JSON.

## Tecnologías

- Python 3.
- JSON para guardar los datos.
- Sin librerías externas.

## Cómo ejecutar

1. Tener Python 3 instalado.
2. Abrir una terminal en la carpeta del proyecto.
3. Ejecutar `python app.py`.

## Funcionalidades

- Registrar solicitudes.
- Cambiar el estado de una solicitud.
- Asignar responsables.
- Listar y filtrar solicitudes.
- Generar un reporte básico.
